# OBI Quest para Android

- `OBI-Quest-1.4.2-android.apk` e o APK de depuracao instalavel, versao 1.4.2
  (`versionCode` 8), compilado com as alteracoes atuais do aplicativo.
- Para instalar, transfira o APK para o aparelho Android e abra-o. Se solicitado,
  permita a instalacao de aplicativos dessa origem.
- O APK usa assinatura de depuracao; nao e uma compilacao assinada para
  publicacao na Play Store.
